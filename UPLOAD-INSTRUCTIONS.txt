민쌤중국어 HSK1·HSK2 통일본 v2 — 업로드 안내

이번 버전은 두 급수의 파일·어휘 구조와 뜻 표시를 통일한 전체 사이트 ZIP입니다.
ZIP을 압축 해제한 뒤 폴더 안의 파일과 하위 폴더를 기존 사이트 최상위 위치에 덮어씁니다.
index.html, lesson.html, hsk1.html, hsk2.html과 data 폴더가 같은 최상위에 있어야 합니다.
ZIP 자체를 저장소에 올리거나 별도의 상위 폴더 아래 전체 사이트를 넣지 마세요.
기존 파일 백업 후 진행하세요. npm 설치나 빌드는 필요하지 않습니다.

GitHub 업로드 순서
1. 기존 사이트 저장소에서 Add file → Upload files를 선택합니다.
2. 압축을 푼 이 버전의 파일과 하위 폴더를 전체 업로드하고 Commit changes를 누릅니다.
3. 예전 mypage-counts.json 파일이 저장소에 남아 있다면 삭제합니다.
   이 파일은 mypage-counts-hsk1.json / mypage-counts-hsk2.json으로 교체됐습니다.
   data/hsk1-vocabulary.js와 audio.js는 삭제하지 마세요.
4. 기존 GitHub Pages 배포가 완료된 뒤 강력 새로고침합니다.
   macOS Chrome: Command + Shift + R
5. HSK1·HSK2 단어 학습과 마이페이지의 코스 전환을 확인합니다.

두 급수 공통 파일 구성
HSK1: data/hsk1-vocabulary.js, data/hsk1-vocabulary.json, mypage-counts-hsk1.json
HSK2: data/hsk2-vocabulary.js, data/hsk2-vocabulary.json, mypage-counts-hsk2.json
JS는 실행용, JSON은 검토·재사용용입니다. 각 급수의 JS/JSON 데이터는 같습니다.
두 급수 모두 동일한 13개 필드로 구성되며 자세한 설명은 data/README.txt에 있습니다.

뜻 표시
- 모든 영어 뜻과 괄호·문법 설명을 보존합니다. 보존된 enOriginal을 생략 없이 표시합니다.
- 별도로 보존돼 있던 HSK1 4개 및 HSK2 1개의 괄호 설명도 화면에서 확인할 수 있습니다.
- 한국어도 해당 설명에 대응하며, 이전 한국어 뜻은 koOriginal에 보존합니다.
- 긴 뜻은 줄 간격·글자 크기·보기 배치로 개선했습니다. 말줄임·숨김·임의 요약은 없습니다.
- HSK1 327개, HSK2 214개 및 과별 순서·고유 ID를 유지합니다.

데이터베이스
이전 HSK2 버전의 database/hsk2-setup.sql을 이미 실행했다면 추가 SQL은 필요 없습니다.
HSK2를 처음 설치한다면 기존 사이트에 연결된 Supabase SQL Editor에서
포함된 database/hsk2-setup.sql 전체를 업로드 전에 한 번 실행합니다.
기존 HSK1 기록을 삭제하거나 초기화하지 않습니다.
운영 서버 권한·트리거·SQL 실행 결과는 이번 로컬 테스트에서 검증하지 않았습니다.

유지 사항
기존 4종 게임, 급수별 기록 분리, 발음 속도 0.82, 평가 닫힘.
HSK2의 15개 레슨은 학습 가능하며 별은 평가가 열리기 전까지 획득하지 않습니다.
테스트용 계정·저장소와 교재 PDF는 ZIP에 포함하지 않았습니다.
