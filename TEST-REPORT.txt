실제 브라우저 검증 (이번 v2 수정본)
테스트용 로그인과 저장소를 사용한 로컬 사이트에서 실시했으며 운영 데이터는 변경하지 않음.
- HSK2 给: 원문의 괄호 설명과 'to; for' 전체 표시 확인.
- HSK1 怎么: 원문의 '(indicating nature, condition or manner, etc.) how' 표시 확인.
- HSK1 怎么: 대응 한국어 '(성질·상태·방식 등을 나타냄) 어떻게' 표시 확인.
- HSK2 得: 긴 문법 어휘 뜻을 모두 표시. 데스크톱 18px, 모바일 17px.
- 모바일 실측 내용 폭 375px: 가로 스크롤 너비도 375px, 가로 넘침 없음.
- 문법 설명을 포함한 플래시카드 앞/뒤 전환 정상.
- 긴 뜻이 있는 모바일 퀴즈 보기를 한 열로 표시하고 원문 전체 표시.
- 단어 매칭 15개 완주 / 오답 0 / 테스트 기록 저장.
- 스피드 퀴즈 15문항 완주 / 정답 15 / 테스트 기록 저장.
- 한자 조합 15문항 완주 / 정답 15 / 테스트 기록 저장.
- 듣기 퀴즈 15문항 완주 / 정답 4 / 테스트 기록 저장 / 틀린 단어 11개 전체 복습 표시.
  듣기 문제는 정·오답 분기를 확인하도록 보기를 선택한 기능 테스트임.
- HSK1·HSK2 마이페이지 최고 기록 조회 및 코스 전환 정상.
- 최종 게임 화면의 브라우저 error 로그 없음.

JS·HTML 내부 스크립트 문법, 로컬 참조 파일 존재, HSK2 214개 수 및 ID,

검증 한계
운영 Supabase 로그인·RLS·트리거와 SQL 실행은 검증하지 않음.
테스트 기록 저장 성공은 로컬 테스트용 저장소 기준임.
HSK1은 기존 사이트에 보존된 원문 데이터를 기준으로 내용 보존을 검증했으며,
이번에 HSK1 PDF 전체를 다시 판독한 것은 아님.
HSK2는 앞선 버전에서 제공된 교재의 生词·专有名词를 이미지로 대조한 자료를 유지함.
교재 영문 표현을 자연스러운 다른 표현으로 임의 교정하지 않음.
